# Dashboard demo screenshots

Screenshots of the Step 4 impact dashboard. To make them, the real `step_1–4.gs` and `Dashboard.html` were run locally in Node with Google's services stubbed out. The data is synthetic records from Step 3's generator: real nonprofit names and CDCR facilities, invented numbers. Today's date is October 25, 2026.
